# 📚 Extensions No NSFW for Mihon & Tachimanga

### Safe Extensions Repository for Mihon & Compatible Apps

A filtered extension repository for Mihon-compatible applications that automatically excludes extensions marked as  **NSFW (+18) ** while staying synchronized with the official  **Keiyoushi ** repository.

مستودع إضافات مفلتر يستبعد تلقائيًا الإضافات المصنفة **(+18)**، مع المزامنة المستمرة مع مستودع **Keiyoushi** الرسمي، دون تعديل ملفات الإضافات الأصلية أو الشيفرة المصدرية.

---

# 📱 Supported Applications | التطبيقات المدعومة

This repository is compatible with applications that support **Mihon / Keiyoushi** extension repositories.

هذا المستودع متوافق مع التطبيقات التي تدعم مستودعات إضافات **Mihon / Keiyoushi**.

| Application | Platform | Official Website |
|-------------|----------|------------------|
| **Mihon** ⭐ Recommended for Android | Android | https://mihon.app |
| **Tachimanga** ⭐ Recommended for iPhone / iPad / Mac | iOS / iPadOS / macOS | https://tachimanga.app |
| **Suwayomi** | Windows / Linux / macOS | https://suwayomi.com |
| **Tachiyomi** *(Discontinued)* | Android | https://tachiyomi.org |

> **Android:** We recommend using **Mihon**, the actively maintained successor to Tachiyomi.
>
> **iPhone / iPad / Mac:** We recommend using **Tachimanga**.

> **مستخدمي Android:** نوصي باستخدام **Mihon**، فهو الخليفة الرسمي لـ Tachiyomi وما يزال يحصل على تحديثات مستمرة.
>
> **مستخدمي iPhone / iPad / Mac:** نوصي باستخدام **Tachimanga**.

> **Note:** Tachiyomi is no longer actively maintained, but older installations may still work with this repository.
>
> **ملاحظة:** توقف تطوير Tachiyomi رسميًا، لكن قد تستمر بعض النسخ القديمة في العمل مع هذا المستودع.

# 🔄 Automatic Updates | التحديثات التلقائية

This repository synchronizes with the official **Keiyoushi** repository every **30 minutes**.

* New extensions are added automatically.
* Existing extensions are updated automatically.
* NSFW extensions are excluded automatically.

يتم تحديث المستودع تلقائيًا كل **30 دقيقة**.

* إضافة الإضافات الجديدة تلقائيًا.
* تحديث الإضافات الحالية تلقائيًا.
* استبعاد الإضافات المصنفة **(+18)** تلقائيًا.
